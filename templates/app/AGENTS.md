# Agent instructions

This is an iOS app built with [mainline](https://github.com/ztaylor/mainline), which takes it from idea to TestFlight
from the command line. Before you build, change or ship it, run `mainline guide` and follow it. Run `mainline help`
for every command; inside this folder, commands need no app name (`mainline test`, `mainline ship`).

Never edit the generated `.xcodeproj`: change `project.yml` and `app.env` instead.
